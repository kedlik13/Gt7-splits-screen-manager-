GT7 RACE NIGHT MANAGER V2

FILES
- index.html: complete app
- manifest.json: installable web app settings
- sw.js: offline cache
- icon-192.png and icon-512.png: app icons

PUBLISH
Upload all five files to the ROOT of your existing GitHub repository and commit to main.
GitHub Pages should publish from main / root.
Open the published URL in Safari, refresh once, then Share > Add to Home Screen.

DATA
Championship data is saved locally on the device in Safari. Use History > Export data to make a JSON backup.
To move results to another phone, export on the first phone and use Import backup on the second phone.
